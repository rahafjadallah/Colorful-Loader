# 🎨 Colorful Animated Loader
A colorful animated loader created using HTML5 and CSS3. This project features overlapping colorful squares with smooth rotation animations and blending effects.

📷 Screenshot


## ✨ Features
- Colorful overlapping square shapes.
- Smooth CSS rotation animations.
- Reverse rotation effect for inner elements.
- CSS Keyframes for animation control.
- Blending effects using `mix-blend-mode`.
- Centered layout using Flexbox.
- Simple and lightweight design.
- No JavaScript required.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Keyframes
- Flexbox
- Positioning
- Mix Blend Mode
- Transform & Scale

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
